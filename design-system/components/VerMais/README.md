Rodapé de lista longa: quanto se vê, quanto existe e o botão para mostrar mais.

Use em deputados, candidatos de um estado e qualquer lista acima de 50 linhas. Evita rolagem infinita, que esconde o rodapé e o menu.

- Mostra "Mostrando X de Y" com uma barra fina de progresso; o botão leva as próximas 50 linhas e o foco vai para a primeira nova.
- Some quando a lista termina, trocado por "Fim da lista".
