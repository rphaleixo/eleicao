Nota em fundo âmbar claro para explicar método, limite de um dado ou que um número é projeção.

Use sempre que um quadro mostrar algo que não é o resultado oficial: projeções de cadeiras, cenários "e se…", somas próprias. A variante `el-aviso--projecao` tem borda tracejada, a mesma linguagem do selo de projeção.

O consumidor fornece: o texto, que deve dizer o que é estimado e, em projeção, o status "em hh:mm, dd/mm/aaaa, com X% das urnas apuradas".

- Texto em `aviso-texto` sobre `aviso-fundo`; não use vermelho para aviso.
- Uma ideia por aviso, máximo três linhas no celular.
- Cenários "e se…" nunca são resultado oficial: o aviso vem antes do número, não depois.
