Use só na primeira visita a uma tela. Se a pessoa já viu aquela tela, mostre o último resultado guardado imediatamente e troque pelos números novos em silêncio.

- `role="status"` e rótulo "Carregando" para leitores de tela; o brilho para com `prefers-reduced-motion`.
- O esqueleto imita o formato do conteúdo (título, bloco, linhas), para a página não pular quando os dados chegam.
- Passou de uns 10 segundos, troque por `Erro` com "Tentar agora".
