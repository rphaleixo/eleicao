Anel com o percentual de urnas apuradas no centro.

Use no cartão principal de cada cargo e na tela de início. Para listas de estados, a barra de `LinhaEstado` ocupa menos espaço.

- Tamanho padrão 72px (56px nos cartões menores); a parte preenchida é `acento`, e `eleito` quando chega a 100%.
- O número fica sempre escrito no centro; o anel não carrega a informação sozinho.
