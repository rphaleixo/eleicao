Painel recolhido com os controles que quase ninguém troca no mapa (colorir por, camada, empates).

Use em Comparar turnos, Geografia e Nulos: o mapa fica logo abaixo do escopo, sem uma pilha de campos antes dele.

- Fechado, ocupa 44px; aberto, empurra o mapa para baixo.
- O resumo mostra os valores ativos ("Cor · camada · turno") para que o estado atual seja legível sem abrir.
- Usa `<details>` nativo: teclado e leitor de tela funcionam sem script.
