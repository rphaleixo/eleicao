Faixa fina com a hora da última atualização, a contagem para a próxima e o botão "Atualizar agora".

Use logo abaixo do topo, sempre visível. Em falha de rede com resultado guardado, ela muda para o estado de erro e mantém os números na tela; `Erro` é só para quando não há nada para mostrar.

- Ponto pulsante em `ao-vivo` enquanto atualiza; no erro vira um quadrado em `perigo`, com a hora do último sucesso escrita.
- Apuração encerrada: troque a contagem por "Apuração encerrada" e deixe só "Atualizar agora".
- `role="status"`: leitores de tela leem a mudança sem interromper.

Orçamento de altura (rodada 6): no funcionamento normal ela não é uma segunda faixa. A hora e a contagem vão dentro do `Topo`. A faixa separada só aparece em falha de conexão ou apuração encerrada, e some quando o problema passa.
